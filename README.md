# Comité Central UEP CDP 2026-2027

Vista de revisión de la página del Comité Central de Padres de Familia de la UEP Concentración Deportiva de Pichincha.

Incluye Inicio, Plan de 8 ejes, Agenda, Cuentas y Participa. Es un prototipo para que el comité revise la apariencia en computadora y en el teléfono. Los envíos, apoyos y recordatorios se guardan solo en el navegador de quien los hace.

Enlace de revisión: https://ideflatinoamerica.github.io/Web_Comite_Central_CDP/

## Desarrollo local

Requiere Node.js.

1. `npm install`
2. `npm run dev`

La página local se abre en `http://localhost:3000`.
